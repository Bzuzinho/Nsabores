# Aplicação de Gestão

Aplicação interna prevista para `app.nsabores.pt`.

Responsabilidades:

- dashboard e indicadores;
- encomendas, clientes e fornecedores;
- produtos, stock, lotes e validades;
- produção de tábuas e cabazes;
- subscrições, eventos, entregas e marketing;
- relatórios, permissões e auditoria.

Tecnologia prevista: Next.js, TypeScript e Tailwind CSS, preparada para futura PWA.
