# Registo de Decisões

Criar um ficheiro por decisão relevante, numerado sequencialmente:

`0001-titulo-da-decisao.md`

Cada registo deve indicar:

- contexto;
- decisão;
- alternativas consideradas;
- consequências;
- estado;
- data.

As decisões não devem ser apagadas quando deixam de vigorar. Devem ser marcadas como substituídas e referenciar a nova decisão.
