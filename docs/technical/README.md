# Documentação técnica

Esta pasta contém documentação técnica consolidada e operacional.

A documentação viva permanece em `docs/living/` e deve acompanhar o estado corrente do projeto. Quando uma decisão, processo ou configuração estabilizar, deve ser consolidada nesta pasta.

## Conteúdos previstos

- arquitetura de sistema;
- modelo de dados;
- autenticação e autorização;
- API e contratos;
- infraestrutura e deploy;
- observabilidade;
- segurança;
- backups e recuperação;
- procedimentos operacionais;
- guias de desenvolvimento.

## Regra de atualização

Uma alteração técnica relevante só está concluída quando a documentação afetada também estiver atualizada.
